# 🧮 C++ Console Calculator

A lightweight console-based calculator built with **C++** that performs basic arithmetic operations using user input.

## ✨ Features

- ➕ **Addition** — adds two numbers.
- ➖ **Subtraction** — subtracts the second number from the first.
- ✖️ **Multiplication** — multiplies two numbers.
- ➗ **Division** — divides the first number by the second.
- 🔄 **Operator Selection** — choose an operation using `+`, `-`, `*`, or `/`.
- ⚠️ **Invalid Operator Handling** — displays an error message when an unsupported operator is entered.
- 🔢 **Decimal Number Support** — uses `double` to handle decimal values.

## 🛠️ Built With

- **Language:** C++
- **Standard Library:** `iostream`
- **Compiler:** GCC / G++

## 🚀 Getting Started

### Prerequisites

Install a C++ compiler, such as GCC or MinGW, to compile and run the program.

### Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
   ```

2. Navigate to the project directory:

   ```bash
   cd YOUR-REPOSITORY
   ```

3. Compile the program:

   ```bash
   g++ main.cpp -o calculator
   ```

4. Run the calculator:

   **Windows:**
   ```bash
   .\calculator.exe
   ```

   **Linux / macOS:**
   ```bash
   ./calculator
   ```
